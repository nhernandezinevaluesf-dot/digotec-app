# 📊 Digotec - Portal Analítico y Cartera de Clientes (Paso 3)

Aplicación web desarrollada en **React (Vite)** como parte de la prueba técnica para el rol de Especialista de Analítica y Automatización Digital en Digotec. La solución simula una interfaz de gestión ejecutiva orientada a interactuar con carteras de clientes, seguimiento de saldos, consumo transaccional y visualización integrada.

## 🚀 Requisitos y Ejecución Local

Asegúrate de tener instalado **Node.js** en tu equipo. Abre la terminal en la carpeta del proyecto y ejecuta los siguientes comandos:

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar el entorno de desarrollo local
npm run dev
